# 파란 청취 실험 도구 — 설계자용

GitHub Pages 배포용 설계자 패키지입니다.

## 포함 파일
- `index.html`
- `designer.js`
- `common/runner-core.js`
- `common/analysis-core.js`
- `common/styles.css`
- `assets/` 아이콘 파일
- `site.webmanifest`
- `.nojekyll`

## 아이콘 자산
`assets/` 안의 아이콘 PNG와 favicon은 **투명 배경으로 다시 생성**했습니다.
모서리 알파값을 검사해 투명 처리를 확인했습니다.

## GitHub Pages
- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

배포 주소 예: `https://사용자명.github.io/paran-listening-experiment-designer/`
