# 파란 청취 실험 도구 — 결과 통계 업데이트 v0.10

이 압축파일에는 **기존 GitHub 저장소에서 교체할 파일만** 들어 있습니다.

## 교체 파일

- `designer.js`
- `common/analysis-core.js`

## 추가 기능

### 참가자별 통계
기존 참가자 요약 통계 아래에 **참가자 문항별 응답 상세**가 추가됩니다.
참가자를 선택하면 제시순서, 문항 ID, 음성파일, 정답, 사용자 선택, 점수, 응답시간, 다시 듣기 등을 볼 수 있습니다.

### 문제별 통계
기존 음성 파일별 통계 아래에 **음성 제공자별 통계**가 추가됩니다.

제공자 ID 추출 방식은 두 가지입니다.

1. 확장자 제외 후 **앞에서 N글자 선택**
2. 확장자 제외 후 **뒤에서 N글자 제외한 나머지**

예: `F32_03.wav`
- 앞에서 3글자 → `F32`
- 뒤에서 3글자 제외 → `F32`

규칙을 변경하면 제공자별 통계가 즉시 다시 계산됩니다.
